Privacy Policy

Dwight Sheets · Effective date: 2026-11-09

Who uses this app

Dwight Sheets is a personal automation tool used only by its owner, Samuel Wong (GitHub: im-samwong). It is not offered to the public and has no other users.

What data it accesses

Dwight Sheets accesses only the owner's own Google account data (Google Drive, Google Sheets, Gmail and Google Calendar), and only to automate the owner's own tasks. It does not access any other person's Google account.

Where data is processed

Data is processed on the owner's own computer and the owner's own server.

Sharing and use

  • No data is sold.
  • No data is shared with third parties.
  • No data is used for advertising.
  • No data is used to train AI models, other than being used to serve the owner's own requests.

Google API Services User Data Policy

Dwight Sheets' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact the owner via the GitHub profile github.com/im-samwong.
